1. LANGUAGES & TECHNOLOGIES USED (YE APP KES KES LANGUAGE SE BANA HAI)
----------------------------------------------------------------------------------------------------

A. PROGRAMMING & SCRIPTING LANGUAGES:
   * TypeScript (Strict typed JavaScript for both Frontend and Backend)
   * JavaScript (ES2022+ / Node.js ESM & CommonJS)
   * HTML5 (Semantic document markup, accessible forms, video player)
   * CSS3 (Modern styling, CSS custom variables, Flexbox, CSS Grid)
   * SQL (PostgreSQL relational schema, RLS policies, tables, constraints)

B. FRONTEND TECH STACK & LIBRARIES:
   * React (Component-driven UI architecture, custom hooks, reactive state)
   * Vite (Next-generation high-speed frontend bundler & dev server)
   * Tailwind CSS (Utility-first responsive design framework)
   * TypeScript (Strict compile-time type safety across all components)
   * Framer Motion (Fluid micro-interactions, page transition animations, modals)
   * Lucide React (Comprehensive SVG icon system)
   * TanStack Query / React Query (Server-state caching, background data revalidation)
   * React Router (Client-side Single Page Application routing, protected route guards)
   * React Hook Form (High-performance form state management)
   * Zod (Schema validation for forms, passwords, user inputs)
   * Recharts (Interactive SVG charts: attendance trends, completion analytics)
   * Axios (HTTP client with JWT interceptors, auto-logout on 401, error handling)

C. BACKEND TECH STACK & LIBRARIES:
   * Node.js (High-performance JavaScript/TypeScript runtime)
   * Express.js (REST API framework, routing, middleware pipeline)
   * TypeScript (Server-side models, controllers, services, interfaces)
   * Supabase Client (@supabase/supabase-js) (Cloud PostgreSQL & cloud storage integration)
   * JSON Engine (Fast local persistent database engine in data/database.json)
   * JSONWebToken (JWT) (Secure signed token generation & stateless authentication)
   * bcryptjs (Cryptographic password hashing with 10 salt rounds)
   * Multer (Multipart/form-data upload handling for avatars, videos, assignments)
   * Helmet (HTTP security headers: CSP, cross-origin policies)
   * CORS (Cross-Origin Resource Sharing configuration)
   * Express Rate Limit (DDoS protection, brute-force mitigation on auth endpoints)
   * Resend API / Nodemailer (Transactional email system: OTP reset, notification emails)
   * Firebase Admin SDK (Firebase Cloud Messaging - FCM push notifications)
   * UUID (v4 universally unique identifiers for database records)

D. DEVOPS, DEPLOYMENT & TOOLING:
   * Vercel Serverless Functions (@vercel/node lambda execution for backend)
   * Vercel Static Hosting (Global CDN delivery for Vite frontend assets)
   * Git & GitHub (Version control and monorepo code tracking)
   * npm (Package management and unified build scripts)

FEATURE MODULE 2: AUTHENTICATION & SECURITY SYSTEM
----------------------------------------------------------------------------------------------------
1. Unified Smart Login:
   - Single clean login screen for both Teachers and Students.
   - Auto-detects user role based on input:
     * Teacher logs in via Username ("teacher" / "sirtatheer") or Email.
     * Student logs in via Username, Roll Number (e.g. "WD-2026-001"), or Email.
   - Secure bcrypt password comparison.
   - Generates JWT token with 7-day expiration.
   - Auto-remembers session in localStorage.

2. Student 3-Step Signup Wizard:
   - Step 1 (Personal Info): Full Name, Username, Roll Number, Mobile Number, Email.
   - Step 2 (Avatar Selection): Preset avatar gallery or custom photo upload with live preview.
   - Step 3 (Security): Password creation with Zod strength validation.
   - Duplicate prevention (checks uniqueness of username, roll number, and email).
   - Auto-login upon successful registration directly into the Student Dashboard.

3. Password Recovery & OTP System:
   - "Forgot Password" request screen.
   - Sends real 6-digit verification OTP to the user's email via Resend API.
   - Secure OTP verification window with expiry timer.
   - Reset password form with confirmation check.

4. Role-Based Route Guards (RBAC):
   - Protected Route wrapper preventing unauthorized access.
   - Teacher-only routes protected against student access (redirects to Unauthorized page).
   - Student-only routes protected against unauthenticated guests (redirects to Login).
   - Automatic token validation and 401 interceptor that clears session and redirects cleanly.

5. Teacher First-Time Setup Flow:
   - Onboarding screen if teacher account has not yet configured profile or credentials.

FEATURE MODULE 5: BACKEND, STORAGE, NOTIFICATIONS & INTEGRATIONS
----------------------------------------------------------------------------------------------------
1. Dual Database Architecture:
   - Primary Persistent Engine: Embedded local JSON store (data/database.json) with auto-deduplication.
   - Serverless Persistence: Automatically seeds into /tmp/data/database.json on Vercel.
   - Supabase PostgreSQL Schema: Complete schema.sql provided with relational tables, foreign keys,
     and Row-Level Security (RLS) policies for scaling to managed PostgreSQL.

2. 3-Tier Resilient Storage Service:
   - Tier 1: Supabase Storage Buckets ("avatars", "course-thumbnails", "course-videos", "assignments").
   - Tier 2: Local filesystem disk storage (/tmp/uploads on Vercel, uploads/ on local).
   - Tier 3: Inline Base64 DataURI fallback (ensures file uploads NEVER fail even without cloud setup).

3. Email Notification Engine:
   - Integrated with Resend API for high-deliverability transactional emails.
   - HTML-styled templates for:
     * 6-digit Password Reset OTP emails.
     * New lesson upload notifications.
     * Attendance warning alerts sent to low-attendance students.

4. Firebase Cloud Messaging (FCM):
   - Firebase Admin SDK integrated for browser push notifications.
   - Device registration endpoint (/api/notifications/fcm-token).

5. Production Vercel Serverless Architecture:
   - Express backend runs as a high-speed Serverless Function via api/index.js.
   - Automatic path restoration via x-matched-path prevents 405 Method Not Allowed errors.
   - Single unified domain deployment: Zero CORS issues, zero cross-origin cookie bugs.
